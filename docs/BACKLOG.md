# SimView backlog (parking lot)

Ideas that might matter but are too uncertain to be requirements yet. Nothing here is planned or
built. Promote an item to the [PRD](PRD.md) only when its go/no-go test is met and the owner agrees.
Started 2026-11-22 alongside PRD 1.5 (draft).

| # | Idea | Why it might matter | Main uncertainty | Go / no-go |
|---|---|---|---|---|
| B-01 | **ROS 2 live bridge**: controllers in SimView publish and subscribe to ROS 2 topics (`/cmd_vel`, `/joint_states`, `/tf`, camera images), so a real ROS stack can drive a SimView robot. | Maya's real stacks are ROS 2; this is the most-asked-for feature in robot sims. | Conflicts with NG7 (no ROS runtime). `rclpy` is not on PyPI; a pure-Python route (rosbridge websocket or Zenoh) adds a dependency and latency. Overlaps VW-33. | Go if the owner relaxes NG7 for an optional extra and a prototype round-trips a `cmd_vel` → pose loop at 50 Hz with < 20 ms latency. |
| B-02 | **PX4 / ArduPilot SITL bridge**: a real autopilot flies SimView's quadrotor over MAVLink in lockstep. | Drone teams test real flight code this way; strong fit for UC-2. | Lockstep timing at 250–400 Hz from Python; needs `pymavlink`; autopilot sensor models must match. | Go if a prototype holds lockstep at 250 Hz at ≥ 1× real time and a PX4 takeoff-hover-land works. |
| B-03 | **Hardware-in-the-loop** with hard real-time pacing to a real controller board. | Last step before flight tests. | NG6 rules it out for MVP and v1; Python timing jitter. | Go only if p99 tick jitter < 1 ms at 1 kHz is measured on Linux, and after B-02. |
| B-04 | **OpenSCENARIO / OpenDRIVE import**: load standard AV scenario and road files into ST-01 scenarios. | Lets AV users bring existing scenario libraries. | Both standards are large; a useful subset may still be big. | Go if a subset (straight and curved roads, ego + NPC lane change, cut-in, braking) maps onto ST-01 in about 2 weeks. |
| B-05 | **Cloud / batch execution**: run sweeps, test suites and evals on remote workers (SSH hosts, Ray or Dask). | Large suites and evals can outgrow one machine. | Conflicts with NG5; new dependencies; determinism across machines (R3). | Go if real use shows local suites routinely take > 1 hour on the reference machine. |
| B-06 | **VLA / foundation-model benchmark tasks**: a small language-conditioned manipulation suite (e.g. "put the red cube in the bin") for evaluating VLA policies through PE-04. | Hot research area; good portfolio story. | Needs a GPU and model licenses; SimView's simple rendering (NG3) may be too far from what VLAs were trained on to get meaningful scores. | Go if PE-04 lands and one open VLA reaches non-trivial success on SimView renders of a Menagerie arm. |
| B-07 | **Fleet operations** for UC-2: order dispatch, route deconfliction and separation, battery and charging, no-fly zones. | Turns the drone fleet demo into a real ops sim; drone delivery companies care about this most. | Shifts SimView toward operations research; scope could grow fast. | Go if the owner wants UC-2 to grow beyond 3 drones and a 20-drone dispatch demo stays ≥ 1× real time. |
| B-08 | **Safety case builder**: link requirements → ST scenarios → evidence (runs, reports) in a claims tree (GSN-lite) exported to HTML. | Certification-minded AV and drone teams need traceable evidence. | Unclear whether SimView's users need this; easy to overbuild. | Go after ST ships if a target user asks for traceability exports. |
| B-09 | **Scenario from a real log**: build an ST-01 scenario (actors, routes, timing) from a real log's tracked objects, then vary it. | "Replay the incident, then perturb it" is how fleets turn failures into tests. Pairs with RI and SR-03. | Real logs rarely include clean object tracks; overlaps VW-31. | Go if one public dataset with object tracks converts into a runnable UC-1 scenario. |
| B-10 | **Learned residual dynamics**: a small network corrects the physics model from real logs, beyond what SR-04 parameter fitting captures. | Narrows sim-to-real gaps that parameters can't explain. | Needs the PyTorch extra in the sim loop; determinism; value over SR-04 unproven. | Go if, on a real log, it cuts SR-03 replay error by > 30% over SR-04 alone. |
| B-11 | **AI scenario authoring**: describe edge cases in words ("20 tricky cut-ins at dusk") and get ST-01 scenario files. | Fast way to grow test suites; pairs with RI-20/RI-21. | Correctness of generated scenarios; needs an LLM API and keys. | Go if RI-21 (MCP server) exists and generated scenarios load and run without hand fixes ≥ 90% of the time. |
